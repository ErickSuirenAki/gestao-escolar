## Atualizações realizadas

Este projeto foi aprimorado com foco na aplicação de conceitos de Programação Orientada a Objetos.

### Implementações:
- Criação da classe `Diretor` com herança de `Usuario`
- Adaptação da classe `Professor` para herança
- Implementação de polimorfismo no método `calculaSalario()`
- Regras de cálculo de salário baseadas em titulação:
  - Especialização: +5%
  - Mestrado: +15%
  - Doutorado: +30%
- Implementação de verificação de bolsa para alunos

### Conceitos aplicados:
- Herança
- Polimorfismo
- Encapsulamento
